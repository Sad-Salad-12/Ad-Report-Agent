# 广告周报 Agent｜可分享脱敏演示包

本目录只包含虚构、可公开演示的内容，不包含生产品牌、产品型号、市场、广告系列、受众、创意、关键词、日期或业务指标。

## 文件说明

- `BRAND_A_Anonymized_Weekly_Report.pptx`：8 页可编辑周报；图表使用合成数据，产品视觉为 AI 生成的虚构设备。
- `DEMO-SOP.xlsx`：脱敏后的 SOP 数据工作簿；原有嵌入图片已移除，图表使用合成数据重新构建。
- `DEMO-weekly-inputs.zip`：可用于测试识别流程的 8 类合成输入文件。
- `BRAND_A_Anonymized_Weekly_Report.json`：周报使用的规范化合成数据。
- `demo_weekly_v1.json` 与 `demo_history_seed.json`：演示配置及合成的上一周期基线。

## 脱敏范围

- 品牌、产品、系列、广告系列、创意、受众和关键词均替换为通用编号或名称。
- 市场、地区、报告周期及全部业务数字均为合成值。
- 产品图片均为 AI 生成的虚构外观，不含商标、包装文字或真实产品素材。
- Office 作者、主题名称、批注、隐藏媒体、关系链接、下载来源及本机路径已清理。
- 压缩包不包含 `__MACOSX`、AppleDouble、`.DS_Store` 或来源网址。

这些材料仅用于产品演示、界面测试和流程说明，不应作为真实业务报告使用。
